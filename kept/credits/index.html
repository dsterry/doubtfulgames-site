Artwork

Project: Kept combines original artwork by Doubtful Games with artwork created using image-generation tools.

  • The archival-paper background, application icon, and handwritten objective-completion strokes were created using ChatGPT/OpenAI image generation.
  • The Chapter 4 tree-branch silhouette was created using Bing Image Creator and edited in Krita.
  • The startup artwork, notebook cover, and game interface icons are original project artwork.
